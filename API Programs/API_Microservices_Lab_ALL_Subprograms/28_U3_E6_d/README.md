# Unit 3 - Experiment 6d) Implement custom sorting using @Query

Source: API & MICRO SERVICES LAB (241AI024), AUS 2025-26 manual.

Spring Boot baseline used for this executable pack: 3.5.6; Java 17.

Run in Eclipse: File > Import > Maven > Existing Maven Projects > select this folder > Finish. Then Maven > Update Project.

Run the main application class. For tests, right-click the test class > Run As > JUnit Test.
